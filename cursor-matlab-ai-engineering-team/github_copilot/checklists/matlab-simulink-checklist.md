- [ ] Correct project and branch baseline opened.
- [ ] Target model(s) and referenced models identified.
- [ ] Signal sources/sinks traced for impacted logic.
- [ ] Data dictionary objects verified (no assumptions).
- [ ] Bus objects verified (names, elements, types).
- [ ] Parameters verified (scope, storage class, units as applicable).
- [ ] Stateflow chart paths and symbols verified (if applicable).
- [ ] Model callbacks and initialization dependencies checked.
- [ ] Sample times/rate transitions reviewed for affected path.
- [ ] Interface contracts preserved or approved for change.
- [ ] Unrelated model sections confirmed untouched.
