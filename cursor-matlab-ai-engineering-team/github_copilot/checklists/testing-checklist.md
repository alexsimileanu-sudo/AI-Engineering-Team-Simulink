# Testing & Validation Checklist (MIL/SIL)

- [ ] Acceptance criteria mapped to test cases.
- [ ] Reproduction test exists for bug scenarios (if bug fix).
- [ ] MIL tests updated/created.
- [ ] SIL tests updated/created.
- [ ] Test environment and versions recorded.
- [ ] Test execution actually performed (or clearly marked not executed).
- [ ] Pass/fail evidence captured.
- [ ] Failing tests listed explicitly (none hidden).
- [ ] Regression scope executed and reported.
- [ ] Coverage/traceability status documented.
- [ ] Validation limitations and open risks documented.
