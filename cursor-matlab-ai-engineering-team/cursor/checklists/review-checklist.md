# Code/Model Review Checklist

- [ ] Scope matches approved plan.
- [ ] Requirements to implementation traceability is explicit.
- [ ] No invented artifacts (signals/buses/params/requirements).
- [ ] Changes are minimal and contained.
- [ ] Interfaces preserved unless explicitly approved.
- [ ] No unrelated files/models changed.
- [ ] Test evidence supports claims.
- [ ] Validation status is truthful (executed vs not executed).
- [ ] Assumptions and risks are clearly stated.
- [ ] Blocking findings identified with concrete references.
- [ ] Final recommendation: Approved / Changes Requested.
